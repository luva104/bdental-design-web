# B-Dental Design

Bilingual static portfolio website for Fabiola Bonilla / B-Dental Design.

## Cloudflare Pages

- Framework preset: `None`
- Build command: leave empty
- Build output directory: `dist`
- Root directory: leave empty

Every push to the production branch will deploy automatically through Cloudflare Pages.

## Local files

The public website is inside `dist/`:

- `index.html`
- `styles.css`
- `app.js`
